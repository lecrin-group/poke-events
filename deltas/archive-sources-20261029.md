# 情報源リスト（2026-10-29 更新）

## 【最優先ルール】src と url は「公式」だけ（2026-10-10 ナギサ決定。毎回この見出しごと次のファイルへ引き継ぐこと）
販売版に向けて、まとめサイトの情報を自分のデータの出どころにしない。
- events の src と url には、**主催者・会場・自治体・大学（実行委員会）の公式ページだけ**を入れる
- 観光協会・観光局のサイト（神奈川県観光協会・名古屋コンシェルジュ・よかなび・ちば観光ナビ・横須賀市観光協会・横浜市観光情報・クロスロードふくおか・東京都公園協会など）は**候補を見つける場所**として使ってよい。載せるときは、詳細ページにある主催者・会場の公式URLをたどって、src・url を公式にする。公式が見つからないときに限り、観光協会のページを src・url にしてよい
- 民間のまとめサイトは**候補を見つける場所だけ**。src・url に入れない。公式で日付を確かめられないものは載せない
　対象：遊ぼう横浜（規約で商用利用を禁止）／東京フェスタ（運営者・規約なし）／Tokyo Art Beat（規約でコンテンツの使用を禁止）／tabemaro（無断転載禁止）／artagenda／駅探／カワゴエ・マス・メディア／グルメプレス／LOCAPOP／MATCHA／名古屋めし.com／ふくおかナビ／さいたま新都心イベント情報／久屋大通・栄イベント情報／ragnet ほか
- **既存データの直し**：10/15に完了（まとめサイト src の残り21件を処理。19件を主催・会場・自治体の公式URL／公式名に差し替え、公式で確認できなかった2件＝ラー1グランプリ2026・けやきの下のマルシェ は削除）。今後は新規追加分だけ公式src化すればよい。観光協会・観光サイト src（神奈川県観光協会・名古屋コンシェルジュ・よかなび・Aichi Now 等）は「公式が見つからないときの代替」なので、余裕がある日に少しずつ公式URLへ差し替える
- 紹介文・写真は今までどおり写さない（事実＋公式リンクだけ）
- 「速攻セット」の遊ぼう横浜は、候補拾いには使ってよいが、載せるのは公式URLにしたものだけ

書式：県コード｜名前｜URL｜状態（使える／取得不可／一般向けなし）｜今日取れた件数｜効率（A/B/C）｜メモ

## コツ（効率の良い方法）
- 最初に既存 events.json を読み、期間内のタイトル一覧と照合してから新規を探す。大きな祭りはほぼ既存にあるので、新規は百貨店催事・美術館企画展・神社マルシェ・学園祭など小〜中規模が中心になる。
- raw の events.json は Actions が終了済みを自動で削るので、ドライブの前回ファイルより件数が少なくても正常（10/4は200件→raw 151件）。
- 一覧ページを curl でまとめて取得し、Python でタグを除去して「10月」「2026年10」を含む行を拾うのが速い。WebFetch は一覧が整ったページ（万博記念公園、赤レンガ倉庫、よかなび、名古屋コンシェルジュ）で有効。
- WebFetch が404・リダイレクトループで失敗しても、curl（UA指定・末尾スラッシュ付き）なら取れることが多い（幕張メッセ、原鉄道、ニューオータニ）。
- 会場カレンダーで「一般／関係者」や日付が構造化されているところ（幕張メッセの「対象」欄、Zepp の rid 付きスケジュール、はまぎん科学館の日付別ページ）は効率A。
- 商業施設・ホテルは /event/ が無いことが多い。トップページのリンクから詳細ページへたどるのが確実。
- 水族館・テーマパークは小さな解説や要予約企画が多い。「予約不要」「当日自由参加」の記載で判断すると速い。
- ドーム・展示場・水族館のイベント一覧URLは推測すると404が多い。先に WebSearch で正しい一覧URLを確認してから取得する。
- JS描画のページ（マリンメッセ福岡、パシフィコ横浜など）は、自治体の公式観光サイト（よかなび、遊ぼう横浜等）経由で拾うほうが早い。
